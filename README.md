## 주요 프로젝트

### 🛠 Unity Core Framework (Prototype)

새 프로젝트마다 다시 만들게 되는 시스템을 하나로 정리한 Unity 베이스 프레임워크입니다.
실제 게임 프로젝트에 쓰면서 문제가 드러난 부분을 계속 리팩토링하며 다듬고 있습니다.

- **[ 🔗 Repository 이동 ](https://github.com/kg8812/Prototype)**

#### 이런 것들을 만들었습니다
- **Behaviour Tree 에디터** — UI Toolkit/GraphView로 직접 제작. 노드 상속만 하면 메뉴에 자동 등록되고, 새 노드 스크립트도 에디터에서 생성
- **게임패드 대응 UI 프레임워크** — 그룹 단위 포커스, 인벤토리 그리드 탐색, 창 간 포커스 이동, 입력 장치 자동 전환
- **Addressables 수명 관리** — 애셋을 Global/Scene 스코프로 묶어 일괄 해제. 씬별 프리로드 매니페스트로 런타임 동기 로드 제거
- **이벤트 기반 전투 구조** — 능력을 인터페이스로 분리해, 유닛이 아닌 오브젝트도 같은 전투 파이프라인을 탐
- **확장 구조** — 버프(Buff/SubBuff 계층), 스킬(사용 방식 5종 교체), 투사체(충돌 반응·확장 컴포넌트 조합)

### 가제 : WinterSpring

2년동안 대규모 팀으로 진행한 2D 메트로베니아 게임프로젝트입니다.
프로젝트에서 개발팀장을 맡아 다양한 게임 시스템 설계와 개발을 담당했습니다.

주요 구현

- 섹터 동적로딩 시스템
- 플레이어 스킬 및 스킬트리
- 무기, 악세서리 시스템
- 비개발자용 섹터 제작 툴 개발
- 스파인 애니메이션 및 이펙트 적용 시스템
- 게임 데이터 관리 시스템

등 다양한 시스템을 구현했습니다.
