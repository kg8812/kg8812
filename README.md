## 주요 프로젝트


### 🛠 Unity Core Framework (Prototype)

현재 가장 활발하게 업데이트 및 리팩토링을 진행 중인 메인 레포지토리입니다. 
새로운 프로젝트 개발 시 공통적으로 요구되는 필수 기능들을 모아 즉각적으로 재사용할 수 있도록 구축한 기반 프레임워크입니다.

- **[ 🔗 Repository 이동 ](https://github.com/kg8812/Prototype)**

#### Key Features
- **Core Systems** : 유닛(플레이어 및 몬스터) 기본 클래스, 투사체 및 공격 오브젝트 처리 구조
- **Managers & Utils** : 리소스, 사운드, 통합 UI 관리 시스템 및 각종 유틸리티 라이브러리
- **Data & Inventory** : JSON 기반 테이블 및 저장 데이터 연동, 아이템 및 인벤토리 시스템
- **Advanced** : 확장성 있는 버프 및 스킬 시스템, 복잡한 AI 제어를 위한 자체 행동트리(Behavior Tree) 툴

### 가제 : WinterSpring

2년동안 대규모 팀으로 진행한 2D 메트로베니아 게임프로젝트입니다.
프로젝트에서 개발팀장을 맡아 다양한 게임 시스템 설계와 개발을 담당했습니다.

주요 구현

- 섹터 동적로딩 시스템
- 플레이어 스킬 및 스킬트리
- 무기, 악세서리 시스템
- 비개발자용 섹터 제작 툴 개발
- 스파인 애니메이션 및 이펙트 적용 시스템
- 게임 데이터 관리 시스템

등 다양한 시스템을 구현했습니다.


[Repository 링크](https://github.com/kg8812/WinterSpring)
